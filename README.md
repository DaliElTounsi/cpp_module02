# C++ Module 02 — Canonical Form, Operator Overloading & Fixed-Point Arithmetic

This **42 School C++ module** focuses on object copy semantics, operator overloading and the implementation of a custom fixed-point number type in C++98.

## What this module demonstrates

- Orthodox Canonical Form
- Copy constructor and copy-assignment operator
- Destructor behavior
- Operator overloading
- Comparison and arithmetic operators
- Increment and decrement operators
- Static helper methods
- Fixed-point arithmetic
- Geometric reasoning with custom numeric types

## Exercise progression

The module builds a `Fixed` number class step by step, then extends it with arithmetic and comparison operators. The final exercise combines `Fixed` values with a `Point` class to determine whether a point lies inside a triangle.

## Why it matters

This module is where C++ objects start behaving like real value types. It teaches how to design classes that can be copied, assigned, compared and used naturally in expressions while maintaining clear ownership and predictable behavior.
